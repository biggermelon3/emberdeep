本轮目标
1. 工具靠近补水站时，仅占用该工具/控件操作手，另一只未靠近受保护控件的空闲手仍能指向并点击界面；各手自身靠近水源/井泵的优先级仍保留。
2. 处于允许交易的阶段（Run.InSupply）时，即使工具仍停靠，也能用空闲手打开 Gear Shop。
3. 打开商店应通过正常归还工具流程断开供水，取消未完成行程或蓄力，不增加水量。
4. 战斗中的购买限制保持不变；不允许通过商店入口绕过交易阶段。

请在本版 APK 安装后分别用左右手、坐姿和站姿验证
[ ] 复现原问题顺序：灭火完成 → 工具仍拿在一手并靠近水源 → 另一手指向 Shop；应出现青色高亮，再由同一空闲手新一次 pinch 打开。
[ ] 交换双手重复；靠近消防栓与已解锁的小溪分别检查。
[ ] 将工具停靠补水站，在允许交易阶段用空闲手点 Gear Shop；进入后工具归还、连接解除、注水停止。
[ ] 压杆或拉泵做半程后尝试进入商店；不得带入半行程、额外补水或在退出商店后补发。
[ ] 记下进入前后的水量与补水计数；仅打开、关闭商店不能增加水量。
[ ] 操作手仍然不会同时点击 UI、开火或操作另一个补水控件；同一次捏合只触发一个动作。
[ ] 保持 pinch 移到 Shop，不应当作新的点击；必须松开后重新 pinch。
[ ] 用一手指向 Shop、另一手捏合，不应错误激活该目标。
[ ] 战斗尚未结束时不能购买；灭火后达到允许交易阶段再正常购买、升级、返回。最终 Won 状态显示 SHOP CLOSED，不能误提示再打一轮或允许购买。
[ ] 注水、半行程或界面悬停中断追/暂停，再恢复时不自动点击、补水或发射。
[ ] 返回商店后再拿工具，捏合井泵、空泵喷溅、旋转阀门、按钮与小溪补水保持原规则。
[ ] 商店和返回路径仍只在 Emberdeep 营地/灭火流程内，不进入其他游戏或共享大厅。
